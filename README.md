# Pertemuan 7 - Aplikasi Flutter

## Deskripsi
Project ini merupakan lanjutan praktikum pengembangan aplikasi mobile menggunakan **Flutter** pada pertemuan ke-7. Pada tahap ini, aplikasi difokuskan pada pengembangan fitur yang lebih kompleks seperti manajemen data, navigasi antar halaman, serta peningkatan interaktivitas pengguna.

## Fitur Aplikasi

Fitur utama yang terdapat dalam aplikasi ini:

- Tampilan UI berbasis **Material Design**
- Navigasi antar halaman (multi-screen)
- Pengelolaan data sederhana
- Interaksi pengguna yang lebih kompleks
- Penggunaan widget lanjutan Flutter

## Cara Menjalankan Project

1. Clone repository
```bash
git clone https://github.com/username/pertemuan7_2306013.git
```

2. Masuk ke direktori project
```bash
cd pertemuan7_2306013
```

3. Install dependencies
```bash
flutter pub get
```

4. Jalankan aplikasi
```bash
flutter run
```
